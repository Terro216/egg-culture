# Яичная Культура (Egg Culture)

Гастрономический и эстетический манифест, возводящий куриное яйцо в ранг спешалти-кофе, коллекционного вина и элитного китайского чая. Ироничный по замыслу, абсолютно серьезный в подаче.

Сайт: `https://egg.<DOMAIN>` (по умолчанию — https://egg.ilyamedve.dev)

Полное описание концепции, философии и архитектуры — в [EGG.md](EGG.md). Исторический план проекта — в [PROJECT_PLAN.md](PROJECT_PLAN.md). Механика закрытой «кладки Фонина» — в [FONIN_PLAN.md](FONIN_PLAN.md).

## Стек

- **Astro 6** — статика (SSG) по умолчанию + SSR-адаптер `@astrojs/node` (standalone) для динамических страниц (`/blog`, `/prophecy`, `/dark-side/fonin`, API-роуты). Закрытый `/dark-side/games` собирается статически и проверяет статус адепта на клиенте.
- **React 19** — точечные интерактивные острова (Island Architecture).
- **Three.js** — 3D-яйцо, шейдеры тёмной стороны и трасса «Пути формы».
- **Rapier 3D (WASM)** — физика асимметричного яйца в «Пути формы», целиком в браузере.
- **d3-geo + topojson-client** — векторная карта терруаров.
- **@resvg/resvg-js** — серверный рендер og-карточек результата теста «Какое вы яйцо?» (SVG → PNG, шрифты в `src/shared/assets/fonts`).
- Нативный Astro i18n (`ru`/`en`) + собственная утилита переводов, без клиентских i18n-библиотек.
- Архитектура — Feature-Sliced Design (`app / pages / widgets / features / shared`).

## Команды

| Команда           | Действие                                    |
| :---------------- | :------------------------------------------ |
| `npm ci`          | Установка зависимостей по lockfile          |
| `npm run dev`     | Dev-сервер на `localhost:4321` (с `--host`) |
| `npm run build`   | Сборка в `./dist/`                          |
| `npm run preview` | Локальный предпросмотр сборки               |
| `npm start`       | Собранный сайт и poller модерации           |

Требуется Node.js >= 22.13 (встроенный `node:sqlite`).

## Испытания адептов

Зал на `/ru/dark-side/games/` и `/en/dark-side/games/` содержит Халаза-тест,
Оракул желтка и прототип **«Путь формы» / Path of Form**. Доступ проверяется
по `egg_adept` в браузере. Игры загружаются по выбору; Three.js и Rapier для
дороги не входят в начальную загрузку зала. Общие испытания не используют
приватные подарки или API кладки Фонина.

Полная игра также доступна без Инициации на `/ru/play/` и `/en/play/`.
Кнопка «Покатить яйцо» на главной открывает её меню; внизу страницы и меню
есть приглашение к Инициации. Используется тот же компонент и то же хранилище,
что и в Зале испытаний. Ссылки на сиды ведут на публичную страницу.

«Путь формы» — спуск по дороге над Пустотой с приземлениями на нижние витки.
Яйцо — динамическое твёрдое тело с выпуклой асимметричной оболочкой;
центр масс и моменты инерции вычисляет Rapier по этой форме. Видимая модель
повторяет физическое вращение, без случайных толчков или скрытого шара.
Это модель цельного твёрдого яйца: жидкий желток и разрушение скорлупы
не симулируются. Непредсказуемость управления возникает из формы и контактов.

В меню есть учебная трасса, последовательное прохождение уровней, бесконечный
режим и ввод сида. Учебная карта — прежние четыре витка, около 857 м. В уровнях
после финиша открывается следующая процедурная карта с петлями, разворотами
и S-образными участками; проверяется зазор между пересечениями. Прогресс
кампании хранится в `egg_road_journey_v1`. Учебные и импортированные карты
не меняют достигнутый уровень.

«Осмотреть ещё раз» плавно отводит камеру назад, затем вращает её вокруг карты.
Яйцо неподвижно, обзор продолжается до нажатия «Подлететь и начать».
Подлёт занимает 4,6 секунды, его можно пропустить. При `prefers-reduced-motion`
переходы мгновенные, обзор статичен. Быстрый повтор сохраняет выбранную карту.

Сиды вида `EGG1-R-2-ABC` содержат версию генератора, вид дороги, уровень и
32-битное зерно в base36. `R` — отдельная карта, `E` — бесконечная дорога.
Можно скопировать код или ссылку `?road=...`, сохранить карту в браузере,
ввести код либо ссылку. Сохранённые карты лежат в `egg_road_maps_v1`; старые
не вытесняются автоматически. Версию `EGG1` нужно сохранять при будущих
изменениях генератора либо поддержать её отдельно, чтобы старые коды работали.

Бесконечная дорога генерируется из сида по участкам с общими вершинами стыков.
Вокруг игрока остаётся до четырёх участков: один позади и два впереди.
Геометрия и коллайдеры пройденных участков удаляются; физика, скорость и очки
на стыке не сбрасываются. Плавающее начало координат сохраняет точность Rapier
в долгих заездах. Повтор восстанавливает начало той же последовательности.

Отметка даёт 100 очков. Дополнительные очки: движение по краю (+14/м),
скорость от 23 м/с (до +20/м), ритм от двух перекатов (+2 × серия/м, до +20/м),
высокое падение от 12 м (+3/м высоты после приземления) и срезки (+35 за
пропущенную отметку). Нужны физический контакт и новое продвижение по трассе;
повторный проезд одного места и неудачное падение бонусов не дают. Итоговый
экран показывает разбивку. В HUD — личный рекорд текущего сида, ключ
`egg_road_track_points_v1`. Учебная карта в разных режимах имеет один рекорд,
а конечная и бесконечная дороги с одинаковым зерном — разные. На карточке
в Зале — только рекорд бесконечного режима из `egg_road_points_v2`. Старые
рекорды без сида не приписываются отдельным картам.

Ритм учитывает реальное боковое перемещение, вращение и смену направления
через 0,28–0,95 с. Индикатор показывает «держите», затем загорается стрелка
смены стороны; рядом видны длина серии и прибавка к скорости. Частые нажатия
без переката не заряжают бонус. Базовая целевая скорость — 18,5–21,5 м/с,
с небольшой прибавкой по сложности; ритм добавляет до 9 м/с. При вылете
с дороги заряд, серия и время переката замораживаются: управление в воздухе
не заряжает ритм, после приземления он продолжается. Короткие подскоки яйца
над полотном остаются частью обычного переката. После вылета даётся 4,2 с
на возвращение; обычные подскоки
над полосой не включают предупреждение. Физика идёт с шагом 1/120 с и CCD.
Коллайдер яйца использует вершины видимой модели, у дороги есть физические
боковины и нижняя поверхность.

Управление: удерживать половину экрана, `←`/`→` или `A`/`D`. Осмотр — потянуть
`◎`, удерживать `Q`/`E` или включить «Обзор наклоном». Наклон и его калибровка
меняют только камеру: оси движения и силы физики от них не зависят.
Кнопка калибровки есть в меню и во время спуска («Ноль»). Разрешение датчика
запрашивается по нажатию, при отказе остаётся ручной обзор. `P`/`Esc` — пауза,
`R` — повтор, `Space` — пропустить подлёт. Горячие клавиши отключены в меню
и при вводе сида. Потеря фокуса ставит игру на паузу. Звук выключен по умолчанию;
его настройка остаётся в `egg_road_v1`.

После заезда можно явно опубликовать результат под именем (до 32 знаков).
`GET/POST /api/egg-road-records` возвращает таблицу для канонического сида:
20 лучших игроков и собственное место, даже если оно за пределами двадцатки.
Одна запись на игрока и сид, обновление только при улучшении; одинаковые очки
дают одинаковое место. Имя и очки публичны, идентификатор игрока — нет.
Идентичность без регистрации: случайная HttpOnly/SameSite-cookie на год,
в базе только её SHA-256. Очистка cookie или другой браузер создают нового
игрока; это не учётная запись с восстановлением доступа. Игра работает
и при недоступной таблице, личные результаты продолжают сохраняться локально.

Сервер хранит записи в SQLite `.kladka/egg-road/records.sqlite` внутри уже
существующего тома `kladka_data`; переопределение — `EGG_ROAD_DATA_DIR`.
Исходные посты и фотографии Кладки не меняются. База использует DELETE journal
и FULL synchronous; для согласованной резервной копии работающей БД используйте
SQLite backup API или `VACUUM INTO`, не копируйте открытый файл произвольно.
`npm test` пишет только во временные каталоги. `.kladka` исключена из Docker build.
Для локальной проверки API задавайте `EGG_ROAD_DATA_DIR` в `/tmp`.

POST требует origin сайта и JSON, ограничен 8 КБ и 20 запросами/минуту с IP;
GET — 120/минуту. IP не пишутся в базу, временный ограничитель хранит только хеши.
Проверяются сид, имя, конечные числа, согласованность дистанции, отметок и суммы
бонусов. Это защита входных данных, а не серверная проверка прохождения:
результаты рассчитываются клиентом и могут быть подделаны модифицированным
клиентом. Серверного воспроизведения заездов и соревновательного античита нет.

Для игры нужен WebGL2. `tests/egg-road*.test.mjs` проверяют настоящую WASM-физику,
стыки и длительное продолжение бесконечной дороги, воспроизводимость сидов,
разделение режимов, защиту очков от повторного проезда, реальное приземление
и езду по краю, подсказки ритма, датчики и калибровку. `check:games` проверяет
игровые модули. В браузере дополнительно сравниваются физические траектории
при одинаковом управлении с наклоном и без него, проверяются подлёт, повторный
обзор, освобождение WebGL-ресурсов, мобильный интерфейс и ссылки на карты.
Чувствительность датчика и частоту кадров нужно оценить на настоящих телефонах.

## Переменные окружения

Смотри `.env.example`:

- `DOMAIN` — базовый домен (сайт живет на поддомене `egg.`).
- `NEWS_API_KEY` — ключ [NewsData.io](https://newsdata.io) для мировой яичной ленты в блоге. Без ключа лента пустая, сайт работает.
- `FONIN_ACCESS_WORD` — кодовое слово закрытой кладки подарков.
- `FONIN_GIFT_TOKEN_SECRET` — секрет подписи временных ссылок на сертификаты (если не задан — используется кодовое слово, задать настоятельно рекомендуется).
- `FONIN_GIFT_PRIVATE_DIR` — путь к директории с PNG-сертификатами (по умолчанию `private/fonin-gifts`).
- `KLADKA_BOT_TOKEN`, `KLADKA_ADMIN_CHAT_ID` — Telegram-бот премодерации Книги Кладки (`/kladka`): записи прилетают админу с кнопками «Одобрить/Отклонить». Ответы забирает встроенный long poller `scripts/kladka-poller.mjs` и передаёт локальному API; публичный Telegram webhook не используется. Без токена записи публикуются сразу. Опционально: `KLADKA_WEBHOOK_SECRET` (подпись внутреннего вызова poller → API), `KLADKA_IP_SALT`, `KLADKA_DATA_DIR`.

После изменения `.env` контейнер нужно **пересоздать**: обычный
`docker compose restart` не перечитывает `env_file`.

```sh
docker compose up -d --force-recreate web
```
