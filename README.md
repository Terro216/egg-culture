# Яичная Культура / Egg Culture

Гастрономический и эстетический манифест, возводящий куриное яйцо в ранг
спешалти-кофе, коллекционного вина и элитного китайского чая.
Справочник, инструменты дегустатора, Книга Кладки и браузерные игры на русском
и английском языках.

[Открыть сайт](https://egg.ilyamedve.dev) · [Концепция проекта](EGG.md)

## Разработка

Требуется Node.js **22.13 или новее**: сервер использует встроенный `node:sqlite`.

```sh
npm ci
cp .env.example .env
npm run dev
```

Сайт доступен по адресу `http://localhost:4321/ru/`; английская версия — `/en/`.
`DOMAIN` задаёт базовый домен для канонического адреса `https://egg.<DOMAIN>`.
Для своей установки укажите его до сборки. Внешние API для локального запуска
не обязательны. Без настроенного Telegram-бота записи Книги публикуются сразу.

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сервер разработки |
| `npm run build` | Сборка в `dist/` |
| `npm run preview` | Предпросмотр сборки |
| `npm start` | Собранный сервер и poller модерации |
| `npm test` | Тесты приложения и игр |
| `npm run check` | Генерация типов Astro и проверка TypeScript |
| `npm run check:games` | Проверка типов игровых модулей |

CI выполняет проверки типов, тесты, сборку и аудит зависимостей.
Браузерные сценарии находятся в `scripts/verify-*.mjs`; сценарии с регистрацией
и записью результатов запускайте на изолированном preview с тестовой базой.

## Устройство проекта

Astro обслуживает статические страницы и серверные маршруты через
`@astrojs/node`. React используется для интерактивных компонентов, Three.js
и Rapier — для трёхмерных игр, SQLite — для аккаунтов и прогресса.
Версии зависимостей зафиксированы в `package-lock.json`.

| Каталог | Содержимое |
| --- | --- |
| `src/pages/` | Страницы `/ru/`, `/en/` и API |
| `src/app/` | Общий layout и стили |
| `src/features/` | Игры и интерактивные функции |
| `src/widgets/` | Крупные блоки страниц |
| `src/server/` | Аккаунты, прогресс и серверная валидация |
| `src/shared/` | Переводы, UI и общие утилиты |
| `src/data/` | Редакционные материалы |
| `public/` | Публичные изображения и иконки |
| `tests/`, `scripts/` | Тесты и инструменты разработки |

## Настройки и данные

Переменные описаны в [.env.example](.env.example). Основные интеграции:

- `NEWS_API_KEY` — лента NewsData.io; без ключа внешняя лента пуста.
- `KLADKA_BOT_TOKEN`, `KLADKA_ADMIN_CHAT_ID` — премодерация Книги в Telegram.
- `KLADKA_DATA_DIR` — каталог Книги; по умолчанию `.kladka`.
- `EGG_ROAD_DATA_DIR` — каталог SQLite; по умолчанию `egg-road` внутри Книги.

Аккаунты, прогресс и Книга хранятся на сервере. Гостевые результаты и
незавершённые партии могут оставаться только в браузере. Новости кэшируются
отдельно. Файлы окружения, пользовательские данные, приватные ресурсы и
локальные отчёты не должны попадать в Git.

Книга поддерживает общедоступные записи и записи для адептов. Ограничение
проверяется на сервере для ленты и фотографий; у вошедшего пользователя
учитывается статус его аккаунта. Реальные записи пользователей не используются
как тестовые фикстуры.

## Запуск в Docker

```sh
docker build --build-arg DOMAIN=example.org -t egg-culture .
docker run --rm -p 4321:4321 --env-file .env \
  -v egg-culture-data:/app/.kladka egg-culture
```

Для доступа по настроенному домену нужен HTTPS reverse proxy. Домен при сборке
и адрес сайта должны совпадать, в том числе для проверок Origin в API.

`docker-compose.yml` содержит вариант установки с внешней сетью `caddy_net`,
метками для Caddy Docker Proxy, SSH-прокси Telegram и отдельным профилем
резервного копирования. Настройка прокси описана в
[telegram-egress.md](docs/telegram-egress.md), резервных копий — в
[backup-policy.md](docs/backup-policy.md). Пути к ключам и конфигурации задаются
локально через `.env`. Установка systemd-таймеров выполняется отдельно.
