# История Яйца: черновик экспозиции

Страница: `/drafts/egg-history-7f3a/`. Самостоятельный статический документ
в `public/drafts/egg-history-7f3a/`; Astro копирует его в клиентскую сборку.
Навигация сайта, sitemap и robots не перечисляют этот адрес. В документе
установлены `noindex, nofollow, noarchive`. Доступ — по прямой ссылке.

11 глав ведут от амниотического яйца к 2026 году. Основной акцент — Русь,
российский фольклор, пасхальная традиция, Фаберже, советская кухня,
промышленное птицеводство и современный прилавок. Под главами раскрываются
ссылки на научные, музейные и библиотечные источники. Даты сказок относятся
к записям; декоративные экспонаты не выдаются за музейные реконструкции.

Страница продолжает существующий стиль: бумага `#f0ead6`, текст `#2b2b2b`,
золотистый акцент `#80600f`, Lora и Playfair Display из шрифтов проекта.
На компьютере экспонат закреплён рядом с текстом; на узком экране — над ним.
Прокрутка нативная. Все действия локальные: лайк не отправляется на сервер,
кулинарные заметки не изображают цитаты из исторической книги.

`history.js` управляет эпохами и интерактивами. `history.css` содержит стили,
адаптивность и режим уменьшенного движения. Без JavaScript скрывается
динамический экспонат, а основной исторический текст и источники остаются доступны.
Шрифты обслуживаются с того же origin; внешние запросы для страницы не нужны.

При отдельной публикации этой страницы достаточно перенести только её каталог
в `public` и `dist/client` образа текущей версии. Пересборка из рабочей папки
с чужими незавершёнными изменениями для такого выпуска не нужна. Возврат
предыдущего образа удаляет черновик из работающей версии.
