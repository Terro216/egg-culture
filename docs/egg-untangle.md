# Халазы судьбы / Chalazae of Fate

Головоломка на `/{lang}/untangle/`: расположить яйца так, чтобы соединяющие
их нити не пересекались. Есть кампания из 24 ступеней, кладка дня и свободная
игра по коду. Регистрация не обязательна.

## Режимы и версии

В обычном режиме яйца можно перемещать по полю. В режиме перестановок
гнёзда фиксированы: игрок выбирает два яйца и меняет их местами.
Победа определяется геометрией, а не совпадением с одним скрытым образцом.

| Версия | Назначение |
| --- | --- |
| `NEST1` | Первая обычная кампания, сохранена для старых кодов |
| `NEST2` | Основной генератор обычного режима |
| `NEST3` | Учебные ступени обычной кампании |
| `KNOT1` | Первая версия перестановок |
| `KNOT2` | Учебные ступени перестановок |
| `KNOT3` | Разнообразные составные фигуры, сохранены для прежних кодов |
| `KNOT4` | Текущий генератор перестановок с калибровкой сложности |

Первые три ступени используют учебные версии `NEST3`/`KNOT2`.
Старые коды, сохранения и отложенные результаты остаются совместимыми.
Прогресс одной ступени не удваивается при смене генератора, а личный результат
хранится для каждого полного seed. Кладка дня меняется в полночь по Москве.

## Генерация и геометрия

`engine.ts` разбирает код, выбирает версию и генерирует воспроизводимую задачу.
`figures.ts` собирает геометрические фигуры и размещает их с безопасными
зазорами. Пересечения, наложения и попадание нити на постороннее яйцо
проверяются общими геометрическими правилами.

В `KNOT4` модуль `difficulty.ts` перемешивает решение обменами и измеряет
найденный путь подсказок. Диапазон сложности растёт по ступеням; это оценка
пути, а не доказательство кратчайшего решения каждого большого поля.
Для небольших полей дополнительно проверяются одно- и двухходовые победы.
Отбор вариантов и размер кеша ограничены. Кеш возвращает независимые копии,
чтобы игра не меняла следующую генерацию того же кода.

## Подсказки и управление

Подсказка сначала ищет немедленную победу, затем короткое продолжение.
Если такого пути не найдено, выбирается шаг к известному допустимому решению.
Число пересечений на промежуточном шаге может вырасти. Повтор подсказки
для неизменившегося поля, в том числе после reload, учитывается один раз.

Доступны касание, мышь и клавиатура, отмена/повтор хода, пауза и сохранение.
Удержание яйца в режиме перестановок выделяет связанную фигуру без обмена;
то же действие доступно кнопкой и клавишей F. Увеличенное поле прокручивается,
отменённое касание не совершает ход. Настройка уменьшенного движения
сохраняет управление без обязательной анимации.

На узком экране есть режим «Только игра»; настройки и уровни можно открыть
отдельно. После свободной партии следующая случайная кладка сохраняет
выбранные механику и сложность.

## Сохранения и профиль

Незавершённая партия сохраняется в браузере. При отказе хранилища интерфейс
сообщает об ограничении. Завершённую гостевую партию можно явно импортировать
в выбранный аккаунт; автоматического переноса при входе нет.

Сервер заново генерирует задачу и проверяет геометрию решения. Для перестановок
каждое исходное гнездо должно быть занято ровно один раз. UUID обеспечивает
идемпотентность, а гостевой результат можно привязать только к одному аккаунту.
Ходы, время и подсказки остаются клиентскими метриками; это не защищённый
от подделки спортивный рейтинг.

Профиль хранит лучшие результаты по seed, кампании, кладки дня и достижения.
Публичный ответ содержит агрегаты, без истории ходов и незавершённых партий.
Подробности API и очереди — в [документации профиля](../src/features/Portal/README.md).

## Карта кода

Основные модули находятся в `src/features/EggUntangle/`:

| Модуль | Ответственность |
| --- | --- |
| `engine.ts`, `random.ts`, `types.ts` | Коды, генерация и типы |
| `geometry.ts`, `figures.ts` | Проверка поля и построение фигур |
| `solver.ts`, `difficulty.ts` | Подсказки и оценка сложности |
| `storage.ts` | Локальная партия и совместимость сохранений |
| `motion.ts` | Отображение обменов |
| `EggUntangle.tsx` | Интерфейс и управление |

Серверная проверка и запись результатов находятся в `src/server/roadRecords.ts`.

## Проверка

```sh
npm run check:games
node --experimental-strip-types --test tests/egg-untangle-*.test.mjs
node --experimental-strip-types scripts/measure-untangle-difficulty.mjs
```

`NEST_SAMPLES` задаёт размер выборки измерений, `NEST_REPORT` — путь отчёта.
Тесты покрывают геометрию, старые коды, сложность, подсказки, сохранения,
импорт гостевых результатов и изоляцию аккаунтов.

Браузерные сценарии `verify-egg-untangle.mjs`, `verify-untangle-figures.mjs`
и `verify-untangle-improvements.mjs` находятся в `scripts/`. Для сценариев
с записью данных нужен изолированный preview. Проверяйте обе локали,
узкий и горизонтальный экран, реальные касания, клавиатуру и reload партии.
